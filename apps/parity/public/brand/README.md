# Brand source

`knowai-icon.svg` is the unmodified symbol served at https://knowai.club/icon.svg, retrieved on 29 October 2026 and reused at the product owner's request. `knowgst-icon.svg` is a byte-identical product asset: both preserve the original KnowAI symbol geometry.

The app, guide and repository pair this symbol with the **KnowGST** product wordmark. CSS masks use the active text color for light/dark mode. The favicon retains the original asset's system-theme styling. Business-profile logos on invoices are separate and are not replaced by product branding.
