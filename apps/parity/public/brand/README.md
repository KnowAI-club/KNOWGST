# Brand source

`knowai-icon.svg` is the unmodified symbol served at https://knowai.club/icon.svg, retrieved on 29 October 2026 and reused at the product owner's request. The app and guide pair this existing KnowAI symbol with the KNOWGST product name. CSS masks preserve its geometry and use the active text color for light/dark mode. The favicon retains the original asset's system-theme styling.
